
# 📝 NoteEasy - Ứng dụng ghi chú cá nhân

NoteEasy là ứng dụng giúp người dùng tạo và quản lý ghi chú một cách đơn giản.

## Chức năng
- Thêm ghi chú mới.
- Chỉnh sửa ghi chú.
- Xóa ghi chú.
- Tìm kiếm ghi chú.
- Tự động lưu dữ liệu trên trình duyệt.

## Công nghệ sử dụng
- HTML
- CSS
- JavaScript
- LocalStorage

## Cách sử dụng
1. Mở website NoteEasy.
2. Nhập tiêu đề và nội dung ghi chú.
3. Nhấn "Lưu ghi chú".
4. Có thể sửa, xóa hoặc tìm kiếm ghi chú.
